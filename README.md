# Талан — математическая грамотность

Первая локальная рабочая версия платформы для 10–11 классов. Два независимых учебных плана (русский и казахский), переключаемый интерфейс RU/ҚАЗ, светлая/тёмная темы. Система оплаты отсутствует.

## Что работает

- Вход по выданному логину и паролю через Better Auth; bcrypt, серверные сессии, ограничение частоты входа, блокировка аккаунта, смена временного пароля.
- 32 позиции в каждой программе. 32 русских и 30 казахских видео из предоставленных ссылок. Казахские №20 и №29 отмечены как готовящиеся.
- Встроенный Google Drive и отдельная ссылка для открытия ролика. **Просмотр подтверждается учеником кнопкой; процент просмотра не измеряется.**
- Реальные ДЗ №2: по 8 вопросов, формулы, варианты A–E и ключи пользователя. Остальные ДЗ не подменены демонстрационными заданиями.
- Серверное сохранение черновиков, три сдачи всего ДЗ, минимум 80% для зачёта, лучший результат. С 8 равновесными вопросами нужно решить минимум 7.
- Проверка чисел, десятичных дробей, обыкновенных дробей, процентов, короткого текста, допуска и альтернативных ответов. Интерфейс редактора пока использует единичные баллы и базовые параметры.
- Ключи не попадают в клиентский код и ответы API до зачёта или исчерпания попыток. После этого показываются ответы и имеющиеся объяснения.
- Проверки группы, доступа, публикации и даты открытия на сервере; расписание абсолютное либо относительно старта потока.
- Админка: список/поиск/пагинация учеников, создание логинов, блокировка, отзыв доступа, сброс пароля, результаты последних 50 сдач ученика, группы, редакторы уроков и вопросов, агрегированная статистика.
- CSV с предварительной проверкой и явным подтверждением создания; до 100 записей за пакет. Новые пароли показываются и выгружаются один раз, не пишутся в журналы.

## Быстрый локальный запуск

Нужны Node.js 22.12+ и pnpm. `pnpm dev` запускает отдельный локальный процесс базы и приложение. Блокировка каталога не позволяет двум локальным серверам открыть одни файлы одновременно. Завершайте запуск через Ctrl+C; в автоматизированном терминале можно отправить строку `stop`.

```sh
pnpm install
pnpm db:generate
pnpm db:local
pnpm db:seed
pnpm dev
```

Открыть `http://localhost:3000`. `db:local` создаёт `.env` с новым случайным секретом, если файла нет. **Существующий `.env` никогда не перезаписывается.** Если он уже есть, заполните его по `.env.example`; для тестовых аккаунтов установите `DEMO_SEED=true`.

Тестовые логины `admin`, `student.ru`, `student.kk` и случайные пароли находятся в `credentials.local.txt`. Файл исключён из Git. В тестовых аккаунтах смена пароля необязательна; у созданных администратором учеников она обязательна. Удалите тестовые аккаунты перед использованием с реальными учениками.

При использовании другого порта измените `BETTER_AUTH_URL`. Открывайте сайт по тому же hostname, который указан в этой переменной: `localhost` и `127.0.0.1` — разные источники для cookies/CSRF.

Локальная база хранится в `.data/postgres`. Это PGlite с PostgreSQL-сокетом на `127.0.0.1:54329` — средство разработки, **не многопользовательский сервер для 500 одновременных учеников**. Приложение всегда использует Prisma и PostgreSQL-драйвер, не открывает файлы базы из обработчиков Next.js. Сокет не имеет рабочего пароля доступа и должен оставаться только на loopback; наружу его не публиковать.

Для проверки собранной версии после `pnpm build` используйте `pnpm preview`: он тоже запускает локальную базу отдельным процессом. Команда `pnpm start` предназначена для рабочего PostgreSQL через `DATABASE_URL`.

## Правила обучения

1. Номер урока относится к его программе, а не к языку интерфейса. RU №2 — вероятность; ҚАЗ №2 — уравнения и вычисления. Прогресс между ними не переносится.
2. Урок завершён, если ученик подтвердил просмотр и ДЗ зачтено.
3. Черновик не расходует попытку. Попытка расходуется только при отправке полного ДЗ. Неполное ДЗ не принимается.
4. Сервер рассчитывает баллы. Повтор запроса с тем же `requestId` возвращает прежнюю сдачу, не списывает новую попытку.
5. После зачёта дальнейшие сдачи закрыты. После третьей неуспешной сдачи требуется помощь преподавателя. API администратора поддерживает дополнительную попытку; отдельная кнопка для неё ещё не добавлена.
6. Процент в текущих сводках округляется вниз до целого. Порог прохождения проверяется по точному соотношению баллов, без округления. Восемь вопросов: 7/8 = 87,5%, сводка показывает 87%.
7. Изменение состава и ключей ДЗ запрещено после появления сдач. До первой сдачи изменение вопросов очищает черновики и увеличивает версию задания.
8. Расписание пробных групп создаётся относительно дня первого запуска, 3 урока в неделю. Это тестовое расписание; реальный старт и дни надо задать в админке.

## CSV

```csv
name,username,cohortId
Тестовый Ученик,talan.test,preview-ru
Сынақ Оқушысы,,preview-kk
```

Пустой `username` создаёт случайный логин. `cohortId` виден на странице групп. Столбцы с ИИН не принимаются. Персональные данные реальных детей в демо не загружать. При частичном сбое импорта выдаются созданные аккаунты и список неудачных строк; повторно импортировать только неудачные строки.

## Проверки

```sh
pnpm typecheck
pnpm test
pnpm exec playwright install chromium
# В другом терминале уже должен работать pnpm dev
pnpm test:e2e
pnpm build
```

Браузерные проверки создают отдельные тестовые аккаунты в тестовой базе; не запускать их на рабочей базе. Используйте отдельное `LOCAL_DATABASE_PATH` и тестовую конфигурацию для автоматизации.

## Подготовка рабочего размещения

Для сервера задайте `DATABASE_URL` PostgreSQL, случайный `BETTER_AUTH_SECRET` и HTTPS-адрес `BETTER_AUTH_URL`. Примените `pnpm db:deploy`. `DEMO_SEED` должен быть выключен. Приложение отказывается работать на локальной базе в production, кроме явно включённого `ALLOW_LOCAL_PREVIEW=true` для локальной проверки сборки.

Cloudflare Workers в этой версии **не настроен и не проверен**: Node-драйвер и запуск локального сервера нельзя переносить туда без отдельной адаптации и проверки. Приложение пока рассчитано на Node.js. Выбор хостинга и размещения реальных персональных данных остаётся отдельным этапом; нельзя считать иностранный бесплатный PostgreSQL автоматически допустимым для базы учеников центра.

До реального запуска ещё нужны:

- Все остальные ДЗ и ключи (31 комплект на каждую программу), два отсутствующих казахских видео.
- Согласованные даты групп, политика повторных попыток после исчерпания лимита и подтверждение ручной отметки просмотра.
- Оформление рабочего хранения персональных данных, резервное копирование и проверка восстановления.
- Нагрузочные испытания для 500 одновременных пользователей. Такого испытания в локальной версии нет.
- Файловое/object storage для изображений в новых заданиях; загрузка изображений, массовый импорт всех ДЗ, переупорядочение уроков, глубокая аналитика вопросов и удаление аккаунтов пока не реализованы.
- Ужесточение CSP для production (текущая конфигурация допускает development scripts), проверка rate limiting за выбранным reverse proxy, журналы и мониторинг.
- Рабочий администратор, домен/технический адрес и проверка воспроизведения видео из сетей учеников. Google Drive по ссылке не запрещает распространение видео вне платформы.

## Источники материалов

- RU: https://docs.google.com/spreadsheets/d/1OQxc3NC8y04wuja_znsta0H4yB0MhDS_zzEoP0S8cOs/edit
- ҚАЗ: https://docs.google.com/spreadsheets/d/1riOPWqF-tb6UFmUyGt5pxD3-UyBOoCcWZ8Ep5LCX188/edit
- Идентификаторы роликов: ссылки пользователя; порядок и названия сверены с CSV-экспортом обеих таблиц.
- ДЗ: «Математическая грамотность 2.pdf» и «Математикалық сауаттылық №2.pdf». Формулы проверены по отрисованным страницам. Ключи взяты из двух скриншотов пользователя.
- RU ключ: C D A C B B E B. ҚАЗ ключ: C C E D A B E A.
- В русском вопросе №4 ответ C предполагает независимость опозданий автобуса и поезда. Оригинальный текст сохранён, требуется уточнение автора.
- Логотип: предоставленный `aaaaa.PNG`, без изменения изображения.

Контент с правильными ответами находится только в серверных seed-файлах. Не делайте репозиторий публичным, если эти ключи должны оставаться закрытыми.
